## PROJECT 1: ResearchMate AI

### AI-Powered Academic Research Assistant

**Category:** Generative AI | Retrieval-Augmented Generation | AI Engineering

**Repository:** [ResearchMate AI](https://github.com/BalogunAyobamiEsther/ResearchMate-AI)


### Project Overview

ResearchMate AI is an AI-powered academic research assistant designed to help students and researchers interact with academic documents, retrieve relevant information, and obtain evidence-based answers to research questions.

The application is built around a Retrieval-Augmented Generation (RAG) architecture that processes uploaded academic PDF documents, retrieves relevant passages, and generates contextually grounded responses supported by source and page citations.

The goal is to make academic research more efficient by reducing the time spent manually searching through lengthy research documents.

### Core Features
- Academic PDF document upload and processing.
- PDF text extraction and document preparation.
- Document chunking for efficient retrieval.
- Text embedding generation.
- Semantic search and relevant passage retrieval.
- Vector storage using ChromaDB.
- AI-powered question answering using Google Gemini.
- Context-aware response generation.
- Source and page-level citation support.
- Evidence inspection and citation validation.
- PDF page navigation through cited references.
- Backend API endpoints for document management and research interactions.

### Technical Contributions
- Designed and implemented the document ingestion pipeline.
- Developed PDF processing and text extraction workflows.
- Implemented document chunking and embedding generation.
- Integrated vector storage and semantic retrieval.
- Developed the RAG workflow connecting document retrieval to LLM response generation.
- Worked on prompt construction and grounded response generation.
- Implemented citation and evidence-handling functionality.
- Developed backend services using FastAPI.
- Integrated database functionality using SQLAlchemy.
- Worked on frontend and backend integration.
- Deployed the backend application using Render.

### Technologies Used

Python | FastAPI | React | JavaScript | Vite | Google Gemini | ChromaDB | PyMuPDF | SQLAlchemy | Pydantic | Git | GitHub | Render

### Project Status

The backend has been deployed on Render. Frontend integration, persistent cloud storage, multi-user data isolation, and additional production-readiness improvements remain ongoing development areas.

## PROJECT 2: SafeSpace AI

### AI-Guided Personal Support & Well-being Platform

**Category:** Generative AI | AI Application Development | Social Impact

**Repository:** [SafeSpace AI](https://github.com/BalogunAyobamiEsther/SafeSpace-AI)

**Live MVP:** [Explore SafeSpace AI](https://343d968b.mydala.app)

### Project Overview

SafeSpace AI is an AI-powered platform designed to provide young people with an accessible space to express themselves, reflect on personal challenges, explore career and academic concerns, and discover helpful resources.

The idea was inspired by an experience during my undergraduate years when I encountered a fellow student experiencing emotional distress alone during an examination period.

That experience made me reflect on how many young people struggle with personal, emotional, and academic challenges without knowing where to turn for support.

I became interested in exploring how Artificial Intelligence could provide an accessible starting point for supportive conversations and resource discovery.

### Core Features

**1. Career Roadmap**
- A dedicated conversational category for career-related questions.
- Guidance around career exploration and professional development.

**2. Academics**
- An interactive space for discussing academic concerns.
- Support for learning-related challenges and educational experiences.

**3. Emotional Well-being**
- A guided space for expressing personal concerns.
- Structured conversations that encourage reflection.
- Exploration of emotional challenges and relevant support resources.

**4. Resource Centre**
- Access to helpful educational and personal development resources.
- Motivational TED Talks and other learning materials.
- Resources that encourage reflection and personal growth.

### My Contributions
- Identified a real-world social problem and translated it into an AI application concept.
- Developed the project vision and objectives.
- Designed the application structure and conversational categories.
- Developed structured prompts and interaction workflows.
- Used prompt-driven development to build the functional MVP.
- Refined the application through iterative testing.
- Worked on interface usability and user experience.
- Explored responsible applications of AI in personal support and well-being.

### Technologies & Development Tools

React 18 | TypeScript | Vite | Tailwind CSS | shadcn/ui | Radix UI | Dala Studio (Gebeya Studio) | Git | GitHub

### Project Status

Functional MVP/prototype.

Future development directions include improved conversational continuity, personalized resource recommendations, stronger privacy safeguards, contextual understanding, and additional pathways to appropriate human support.

**Responsible AI Consideration:** SafeSpace AI is intended as a non-clinical support platform. It does not replace professional mental healthcare, therapy, diagnosis, or emergency intervention.
